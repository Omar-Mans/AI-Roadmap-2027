# 🟢 Level 1: Beginner

[⬅ Back to overview](../README.md) · Next: [📊 Data Analysis](../02-data-analysis/README.md) **or** [🟡 Machine Learning](../03-machine-learning/README.md) ➡

**Goal:** become comfortable with Python, its data packages (NumPy, Pandas, Matplotlib, Seaborn), and the statistical language used in all data work. This level is the **shared foundation** for both tracks.
**Duration:** 10–12 weeks at ~10 hrs/week.

### 📅 Weekly Plan

| Weeks | Topic | Outcome |
|:--:|:--|:--|
| **1–4** | [Python Basics](#1-python-basics) | Write small programs without copying a tutorial |
| **5** | [OOP](#2-object-oriented-programming-oop) | Organize a program into classes |
| **6–7** | [Statistics & Probability](#3-statistics--probability) | Explain descriptive stats, distributions, and hypothesis testing |
| **8–9** | [Python for Data](#4-python-for-data-packages): NumPy & Pandas | Load, filter, group, and merge real datasets |
| **10** | [Python for Data](#4-python-for-data-packages): Data Cleaning & RegEx *(+ Web Scraping, optional)* | Turn raw data into a reliable dataset |
| **11** | [Python for Data](#4-python-for-data-packages): Matplotlib & Seaborn, EDA | Find and show patterns with evidence |
| **12** | Buffer week + [checkpoint project](#-level-1-checkpoint) | EDA notebook on GitHub |

> Fast learners can finish in **10 weeks** by skipping the buffer week and the optional web scraping.

### 🔀 After this level, choose your goal

| Your goal | Next level |

## ✅ Level 1 Checkpoint

- Write functions and classes independently, without copying a tutorial line by line.
- Explain mean, median, variance, standard deviation, distributions, and hypothesis testing in simple terms.
- Manipulate real tabular data with Pandas and build readable plots.
- **Mini project (after week 7):** a small **CSV summary tool** in Python that reads a CSV and prints column types, missing values, and descriptive statistics.
- **Checkpoint project (week 12): EDA notebook.** Pick a real-world dataset and publish a notebook on GitHub with:
  - a short description of the dataset and the questions you investigate,
  - data-quality checks and documented cleaning decisions,
  - appropriate visualizations and summary statistics,
  - at least three findings supported by evidence,
  - a concise conclusion and known limitations.
