# 🟢 Level 1: Beginner

[⬅ Back to overview](../README.md) · [Next: Data Analysis ➡](../02-data-analysis/README.md)

**Goal:** become comfortable with Python programming and the statistical language used in all data work.
**Duration:** 6–8 weeks at ~10 hrs/week.

### 📅 Weekly Plan

| Weeks | Topic | Outcome |
|:--:|:--|:--|
| **1–4** | [Python Basics](#1-python-basics) | Write small programs without copying a tutorial |
| **5** | [OOP](#2-object-oriented-programming-oop) | Organize a program into classes |
| **6–7** | [Statistics & Probability](#3-statistics--probability) | Explain descriptive stats, distributions, and hypothesis testing |
| **8** | Buffer week + [checkpoint project](#-level-1-checkpoint) | CSV summary tool on GitHub |

> Fast learners can finish in **6 weeks** by merging the buffer week into weeks 6–7.

## ✅ Level 1 Checkpoint

- Write functions and classes independently, without copying a tutorial line by line.
- Explain mean, median, variance, standard deviation, distributions, and hypothesis testing in simple terms.
- **Project:** build a small **CSV summary tool** in Python (reads a CSV, prints column types, missing values, and descriptive statistics) and publish it on GitHub with a README.
